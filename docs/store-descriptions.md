## English

### Short summary

Close the current tab by double-clicking the middle mouse button.

### Detailed description

Double-click the middle mouse button on a webpage to close the current tab.

Adjust the double-click interval from the popup or settings page.

Limitations:

- Reload existing tabs after installation or updates.
- Browser settings pages and extension store pages are not supported.

## 日本語

### 短い説明

マウスの中ボタンをダブルクリックして、現在のタブを閉じます。

### 詳しい説明

Web ページ上でマウスの中ボタンをダブルクリックすると、現在のタブが閉じます。

ダブルクリックの判定間隔は、ポップアップまたは設定ページで調整できます。

制限事項：

- インストール・更新後は、開いているタブを再読み込みしてください。
- ブラウザーの設定ページや拡張機能ストアのページでは利用できません。

## 한국어

사용 제한:

- 설치하거나 업데이트한 후에는 열려 있는 탭을 새로고침하세요.
